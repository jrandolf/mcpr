# Contributing

AI agents maintain this repository. Reviewing an unsolicited pull request takes us longer than having our agents implement an approved proposal, so we review ideas before code.

## Propose a change

1. [Start a GitHub Discussion](../../discussions/new) describing the problem and your proposed change.
2. Wait for a maintainer to review the discussion.
3. If we accept the proposal, a Mathematic maintainer or agent will open the pull request.

We automatically close unsolicited pull requests. Only Mathematic organization members, repository collaborators, and approved maintenance bots may open pull requests.
